# Bounded Task

1. 先由 `gpt-5.6-sol/high` 主线程确认目标、文件边界、验收方式，并排除需要 Change Contract 的改动。
2. 读取、编辑和验证工作足以抵消委派开销时，启动一个 `gpt-5.6-terra/medium` 子代理；极小任务由主线程直接完成。
3. 仅向子代理传递目标、精确范围、硬约束和验证命令；不得扩展范围，也不得与其他代理同时写同一语义区域。
4. 主线程重新读取实际改动，执行对应验证，并对最终结果负责。
