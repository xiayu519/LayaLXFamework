# Bounded Task

1. 主线程确认目标、文件边界、验收方式，并排除需要 Change Contract 的改动。
2. 默认由当前代理直接完成；仅当用户明确要求委派时才启动继承主线程模型的子代理。仅在用户授权降成本时显式选择较低档执行模型。
3. 委派时仅传递目标、精确范围、硬约束和验证命令；不得扩展范围，也不得与其他代理同时写同一语义区域。
4. 主线程重新读取实际改动，执行对应验证，并对最终结果负责。
